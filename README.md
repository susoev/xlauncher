# xlauncher

Лаунчер изолированных профилей Chromium для Windows: свои куки, отпечаток и прокси у каждого профиля, перенос профиля копированием папки, управление через API/MCP и доступ ИИ-агента к браузеру через CDP.

Спецификация — [ARCHITECTURE.md](ARCHITECTURE.md).

## Статус

- [x] Этап 1 — проверка рисков (`spike/`)
- [x] Этап 2 — автообновления: загрузчик, CI-релизы, установка и откат
- [ ] Этап 3 — ядро и раннер: профили, прокси, запуск
- [ ] Этап 4 — API и интерфейс
- [ ] Этап 5 — MCP и доступ агентов
- [ ] Этап 6 — импорт, загрузка движка и геобазы

## Установка

1. Создай пустую папку, например `C:\xl`. В ней будет жить всё: программа, профили, журналы.
2. Скачай [xlauncher.exe](https://github.com/susoev/xlauncher/releases/latest/download/xlauncher.exe) в эту папку.
3. Запусти. Windows может показать «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (один раз).

При первом запуске загрузчик скачает последнюю версию приложения (~20 МБ) и откроет окно.

Дальше обновления ставятся сами: каждый push в `main` собирается в GitHub Actions, и запущенный лаунчер в течение 15 минут скачивает новую версию и перезапускается. Если новая версия не запустилась, загрузчик откатывается на предыдущую.

## Устройство папки

```
C:\xl\
  xlauncher.exe          загрузчик (меняется редко, обновляется сам)
  app\<версия>\          приложение: встроенный Python + код
  app\current.txt        активная версия
  app\previous.txt       предыдущая — для отката
  app\bad.txt            версии, которые не запустились
  run\                   служебные файлы работающего приложения
  logs\                  bootstrap.log, app.log
```

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest -q                      # тесты приложения
(cd bootstrap && go test ./...)          # тесты загрузчика
cd src && python -m xlauncher            # запуск из исходников (без автообновлений)
```
