# Этап 1 — проверка рисков

Одноразовый скрипт, который до основной разработки проверяет на реальном Windows:

- запуск fingerprint-chromium с флагами отпечатка;
- локальный форвардер прокси с логином и паролем (`forwarder.py`);
- что отпечатки разных профилей различаются, а у одного профиля стабильны между запусками;
- что реальный IP не утекает через WebRTC;
- перенос профиля на «другой компьютер» без потери кук (§7.1 в ARCHITECTURE.md);
- как браузер выглядит для антибот-сайтов (по желанию, вручную).

## Запуск

Нужны git и [uv](https://docs.astral.sh/uv/). uv сам поставит Python и зависимости в изолированное окружение, в систему ничего не устанавливается.

```powershell
# один раз: установить uv
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
$env:Path = "$env:USERPROFILE\.local\bin;$env:Path"   # чтобы uv был виден в этом же окне

# склонировать репозиторий и запустить
git clone https://github.com/susoev/xlauncher C:\xlauncher
cd C:\xlauncher
uv run spike\stage1.py
```

Скрипт:

1. скачает последний релиз движка (~150–200 МБ) в `spike\out\engines\`;
2. спросит строку прокси для двух тестовых профилей (ввод скрыт, никуда не отправляется);
3. несколько раз откроет и закроет окна браузера — ничего не трогай, это 2–3 минуты;
4. сохранит отчёт в `spike\out\report.md` и `spike\out\report.json`;
5. в конце предложит открыть профиль на сайтах проверки отпечатка.

Папка `spike\out\` в git не попадает: там тестовые профили, отчёт и твой реальный IP.
