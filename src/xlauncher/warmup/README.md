# Прогрев профилей

`sites.json` — список площадок для прогрева. Правки в `main` приезжают в лаунчер автообновлением.
Чтобы поменять список только на одном компьютере, положи свой файл в `<корень лаунчера>\warmup\sites.json` —
он важнее встроенного.

Блок `timing` — тайминги для всех сайтов:

| Поле | Что значит |
|---|---|
| `between_sites_sec` | пауза между сайтами, `[от, до]` секунд |
| `page_load_timeout_sec` | сколько ждать загрузки страницы |
| `after_load_sec` | пауза после загрузки, прежде чем действовать |
| `scroll_pause_sec` | пауза между сериями прокрутки |
| `scroll_ticks`, `scroll_tick_px` | сколько «щелчков» колеса в серии и по сколько пикселей |
| `scroll_up_chance` | вероятность прокрутить вверх (0–1) |
| `reading_pause_chance`, `reading_pause_sec` | вероятность и длительность паузы «на чтение» |
| `internal_pages` | сколько внутренних страниц открыть на сайте, `[от, до]` |
| `typing_delay_sec` | задержка между символами при вводе запроса |

Поля сайта:

| Поле | Что значит |
|---|---|
| `name` | название для журнала |
| `domain` | домен: в выдаче ищется ссылка на него, внутренние переходы — только в его пределах |
| `url` | адрес для прямого захода (если поиск не нашёл сайт) |
| `query` | что вводить в поиск — как написал бы человек |
| `dwell_sec` | сколько секунд провести на сайте: `[от, до]`, выбирается случайно |
| `actions` | сценарий из исходного списка; сейчас выполняется универсально: листание, паузы, 1–2 внутренние ссылки |
| `yandex` | сайт Яндекса — на IP из дата-центра почти всегда даёт капчу; можно пропускать |
| `enabled` | `false` — не использовать |

Чтобы убрать сайт — поставь `"enabled": false` или удали запись.
